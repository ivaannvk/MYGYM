1. Resumen Ejecutivo (Abstract)

El proyecto Mi Gym consiste en el diseño, desarrollo e implantación de una aplicación web completa y modular concebida para profesionalizar y automatizar los flujos de trabajo de entrenadores personales y nutricionistas. El sistema aborda las limitaciones críticas de las herramientas tradicionales como hojas de cálculo o documentos estáticos, proporcionando una interfaz web intuitiva, reactiva y optimizada para dispositivos móviles.

Entre sus innovaciones técnicas destacan la planificación de ejercicios con desglose individualizado de series (peso en kg y repeticiones específicas), gestión de vídeos demostrativos integrados (alojamiento local en servidor o enlaces externos como Google Drive y YouTube), creador de dietas multi-menú con cálculo dinámico instantáneo de macronutrientes y distribución en un solo clic a través de WhatsApp y PDF.

2. Objetivos del Proyecto

2.1. Objetivo General

Construir una plataforma web integral en PHP y MySQL con arquitectura modular y diseño responsivo que centralice la confección, cálculo y distribución de planes de musculación y pautas nutricionales personalizadas para clientes.

2.2. Objetivos Específicos

  • OE-1: Desarrollar un catálogo nutricional editable con cálculo proporcional automático de calorías y macronutrientes por cada 100 gramos.
  • OE-2: Crear un diseñador de rutinas de entrenamiento con desglose serie a serie y soporte multimedia sin límite de ejercicios ni restricciones de tamaño en la subida de vídeos.
  • OE-3: Implementar un planificador de dietas que permita organizar múltiples opciones de menú para un mismo cliente y calcular en vivo los balances calóricos.
  • OE-4: Diseñar un visor de cliente con reproductor de vídeo integrado y exportación omnicanal mediante enlaces estructurados a WhatsApp y hojas de estilo optimizadas para PDF.
  • OE-5: Garantizar la seguridad mediante sentencias preparadas contra inyección SQL y saneamiento contra XSS.

4. Modelo de Datos y Estructura Relacional

La base de datos relacional migym se compone de 7 tablas normalizadas, organizadas para mantener la trazabilidad completa entre clientes, planes, ejercicios y macronutrientes: 

┌──────────────┐          ┌────────────────────┐          ┌───────────────┐
│   alimentos  │          │      rutinas       │          │     dietas    │
└──────┬───────┘          └─────────┬──────────┘          └───────┬───────┘
       │                            │                             │
       │                            ▼ 1                           ▼ 1
       │                  ┌────────────────────┐          ┌───────────────┐
       │                  │  rutina_ejercicios │          │   dieta_dias  │
       │                  └─────────┬──────────┘          └───────┬───────┘
       │                            │                             │
       │                            ▼ 1                           ▼ 1
       │                  ┌────────────────────┐          ┌───────────────┐
       └─────────────────>│    rutina_series   │          │ dieta_comidas │
                          └────────────────────┘          └───────────────┘

Detalle de Tablas Principales:

  • alimentos: id, nombre, calorias, proteinas, carbohidratos, grasas, categoria, created_at.
  • rutinas: id, cliente_nombre, cliente_telefono, cliente_email, titulo, notas, fecha.
  • rutina_ejercicios: id, rutina_id (FK), ejercicio, series, repeticiones, peso, descanso, video_url, notas.
  • rutina_series: id, ejercicio_id (FK), rutina_id (FK), num_serie, peso, repeticiones, notas.
  • dietas: id, cliente_nombre, cliente_telefono, cliente_email, titulo, notas, total_calorias, total_proteinas, total_carbos, total_grasas, fecha.
  • dieta_dias: id, dieta_id (FK), nombre_dia, orden.
  • dieta_comidas: id, dieta_id (FK), dia_id (FK), comida_tipo, alimento_nombre, gramos, calorias, proteinas, carbohidratos, grasas.

5. Desarrollo e Implementación de Módulos

5.1. Módulo de Rutinas con Series y Vídeos Demostrativos

A diferencia de los gestores convencionales, el módulo de musculación permite desglosar de forma hiper-detallada las cargas de trabajo de cada serie (peso y repeticiones). Además, soporta la subida directa de archivos de vídeo (MP4, WEBM) o el enlace a Google Drive y YouTube. En la visualización del cliente, cada ejercicio dispone del botón 🎥 Video que despliega un reproductor integrado para ver la técnica en el gimnasio sin abandonar la sesión web.

5.2. Módulo Nutricional con Dietas Multi-Día

Permite confeccionar planes divididos en múltiples opciones de menú (Día 1, Día 2, etc.). Al modificar los gramos de cualquier ingrediente, JavaScript recalcula en tiempo real las calorías y los macronutrientes correspondientes. En la cabecera del visor del cliente se sitúa un banner destacado con los totales acumulados de Kcal, Proteínas, Carbohidratos y Grasas, sincronizado con las pestañas de selección de día.

5.3. Módulo de Distribución Omnicanal (WhatsApp y PDF)

El sistema genera una plantilla de texto formateada con caracteres de negrita (`*`) y emojis descriptivos, permitiendo al entrenador enviar el plan completo al WhatsApp del cliente con un solo clic mediante la API Click-to-Chat. Asimismo, la hoja de estilo `@media print` adapta el documento para generar un PDF formal listo para guardar o imprimir.

6. Medidas de Seguridad y Optimización

Protección Integral Implementada:
  • Prepared Statements: Consultas SQL parametrizadas para evitar ataques de inyección SQL.
  • Sanitización XSS: Filtrado con htmlspecialchars() en todas las salidas HTML.
  • Directivas de Servidor (.htaccess): Límite de carga de 1.000 MB y subida de archivos de hasta 500 MB para evitar interrupciones al transferir vídeos de alta definición.
